UNO 联机版 — 使用说明
====================

【怎么开始（联机）】
1. 双击「start.command」
   · 首次可能被 macOS 拦截（"无法验证开发者"）：右键 → 打开，
     或在终端执行一次：chmod +x start.command
2. 浏览器会自动打开  http://localhost:8787
3. 选「在线联机」，按大厅里的"联机三步走"操作即可

【单人 / 同屏多人（不需要服务器）】
直接选「单人模式」或「多人模式」即可开始，和电脑或同屏朋友对战。

【在线联机（和朋友一起玩）】
房主（运行 start.command 的人）：
  · 进游戏选「在线联机」→ 点「创建房间」。
    大厅会显示：4 位房间号、本机二维码、以及"分享链接 / 复制邀请"。
  · 把二维码或链接发给朋友最省事（含房间号，对方打开即填好）。
朋友（同一台电脑 / 同一 Wi-Fi / 跨网络）：
  · 同一台电脑：浏览器打开  http://localhost:8787  → 在线联机 → 加入房间。
  · 同一 Wi-Fi：浏览器打开  http://<房主电脑IP>:8787
        （大厅里会自动显示"同 Wi-Fi 的好友请填：ws://x.x.x.x:8787"）
  · 跨网络（不同城市）：见下方"不在同一 Wi-Fi 怎么办"。
房主点「开始游戏」，所有人自动同步进入对局。

【不在同一 Wi-Fi / 跨网络怎么办】
有三种方式，按推荐顺序：
  1) 分享链接 / 二维码（最简单）
     房主大厅点"复制邀请"或扫二维码，朋友打开链接即可自动带上房间号。
     只要朋友能访问房主的地址就能连（配合方式 2/3 即可跨网络）。
  2) Cloudflare 隧道（推荐，免费、零配置）
     房主安装 cloudflared（brew install cloudflared）后，在大厅点
     "启用公网隧道"，会得到一个 trycloudflare.com 的公网地址，
     发给朋友即可，无需公网 IP / 路由器端口转发。
     未安装时按钮会提示去装，且不影响同 Wi-Fi 对局。
  3) 路由器端口转发 + 公网 IP
     在房主路由器把 TCP 8787 转发到房主电脑，再把公网 IP 发给朋友。
     （这种方式需要你有公网 IP，且有一定安全风险，一般不推荐。）

【二维码 / 隧道 依赖说明】
  · 二维码由服务端的 qrcode 模块生成，已打包在 node_modules/qrcode，
    无需联网、无需 npm install。
  · 公网隧道依赖本机已安装的 cloudflared；没有就走方式 1 + 同 Wi-Fi，
    或自行安装 cloudflared 后点"启用公网隧道"。

【停止服务器】
关闭运行 start.command 的终端窗口即可；
或终端执行：lsof -ti tcp:8787 | xargs kill

【需要联网吗？】
不需要。ws 依赖已打包在 node_modules 里，把整个「UNO联机版」文件夹拷走
就能在另一台 Mac 上直接双击运行。

【文件夹里都有什么】
  index.html / style.css        网页与样式
  i18n.js cards.js engine.js     规则引擎与多语言
  ai.js ui.js sound.js net.js    电脑对手 / 界面 / 音效 / 联机客户端
  main.js                       控制器（串联一切）
  server.js                     联机服务器（托管网页 + 中转）
  node_modules/ws              WebSocket 依赖（已打包）
  node_modules/qrcode          二维码生成依赖（已打包）
  start.command                 双击即启动服务器并打开游戏
